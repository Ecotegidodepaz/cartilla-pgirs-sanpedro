## ⚠️ Archivos que NO DEBEN Existir

Estos archivos/carpetas NO deben estar en tu proyecto antes de subirlo:

- ❌ `node_modules/` - Se descarga con `yarn install`
- ❌ `.next/` - Se genera con `yarn build`
- ❌ `.build/` - Cache de build
- ❌ `*.log` - Archivos de registro
- ❌ `.DS_Store` - Archivos de Mac
- ❌ `Thumbs.db` - Archivos de Windows

**Nota**: Estos archivos están protegidos por `.gitignore` y NO se subirán a GitHub.

## 🚨 Errores Comunes y Soluciones

### Error 1: Faltan archivos de components/ui

**Síntoma**: Errores de importación al ejecutar `yarn dev`

**Solución**: Asegúrate de descargar TODA la carpeta `components/ui/` completa

### Error 2: Falta pgirs_content.json

**Síntoma**: Error al cargar datos

**Solución**: Verifica que `public/pgirs_content.json` existe y tiene contenido

### Error 3: Faltan imágenes de logos

**Síntoma**: Logos no se muestran

**Solución**: Verifica que `public/logos/` contiene los 3 archivos PNG

### Error 4: .gitignore vacío o inexistente

**Síntoma**: Git quiere subir node_modules (50,000+ archivos)

**Solución**: Crea `.gitignore` con el contenido correcto (ver más arriba)

## ✅ Comando de Verificación Completa

Copia y pega este script en tu terminal para verificar TODO:

```bash
#!/bin/bash

echo "🔍 Verificando estructura del proyecto..."
echo ""

# Función para verificar archivo
check_file() {
    if [ -f "$1" ]; then
        echo "✅ $1"
    else
        echo "❌ FALTA: $1"
    fi
}

# Función para verificar carpeta
check_dir() {
    if [ -d "$1" ]; then
        echo "✅ $1/"
    else
        echo "❌ FALTA: $1/"
    fi
}

# Verificar archivos principales
echo "📄 Archivos de configuración:"
check_file "package.json"
check_file "tsconfig.json"
check_file "next.config.js"
check_file "tailwind.config.ts"
check_file ".gitignore"
check_file ".env"
check_file ".env.example"

echo ""
echo "📚 Documentación:"
check_file "README.md"
check_file "LICENSE"
check_file "PUBLICAR_EN_GITHUB.md"
check_file "GUIA_VSCODE.md"

echo ""
echo "📁 Carpetas principales:"
check_dir "app"
check_dir "components"
check_dir "lib"
check_dir "public"
check_dir "hooks"

echo ""
echo "🎨 Subcarpetas de components:"
check_dir "components/ui"
check_dir "components/charts"
check_dir "components/sections"

echo ""
echo "🖼️ Subcarpetas de public:"
check_dir "public/logos"
check_dir "public/pgirs_images"

echo ""
echo "📊 Estadísticas:"
echo "Archivos en components/ui: $(ls -1 components/ui/ 2>/dev/null | wc -l)"
echo "Logos en public/logos: $(ls -1 public/logos/ 2>/dev/null | wc -l)"

echo ""
echo "🔐 Verificación de seguridad:"
if grep -q ".env" .gitignore 2>/dev/null; then
    echo "✅ .env está protegido en .gitignore"
else
    echo "❌ ¡PELIGRO! .env NO está en .gitignore"
fi

echo ""
echo "✅ Verificación completa"
```
